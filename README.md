# Banking App — учебный список пользователей

Небольшое приложение на React для тренировки работы с состоянием и формами. Можно добавлять пользователей, редактировать их данные и удалять записи. Данные хранятся только в памяти браузера и исчезают после обновления страницы; банковских операций или сервера здесь нет.

## Запуск

```bash
cd banking-app
npm ci
npm start
```

Для проверки сборки: `npm run build`.
